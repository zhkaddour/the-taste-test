# Doctrines

Distilled "doctrines" of great problem-pickers. Each persona has a folder; the
eval runner discovers everything automatically — no map to maintain.

## Structure

```
doctrines/
└── <person-slug>/
    ├── doctrine-light.md          # short version (always present)
    └── doctrine-distilled.md      # full version (optional)
```

Slug uses dashes, e.g., `peter-thiel`, `richard-hamming`. The runner loads each
`doctrine-<variant>.md` as a distinct persona, so light and distilled versions
of the same person can be compared directly on the leaderboard.

## Adding or extending a doctrine

1. Drop the markdown into `doctrines/<person-slug>/doctrine-<variant>.md`.
2. Re-run the eval — the runner picks it up on the next start.

## Naming convention for personas

Auto-generated by the runner from the layout:

- `peter-thiel__light` → "Peter Thiel (light)"
- `peter-thiel__distilled` → "Peter Thiel (distilled)"

## Light vs. distilled — selective evaluation

A `light` doctrine is a short stub (~300 chars). A `distilled` is a much richer
~30-60K-char synthesis. The runner's loading policy:

- **Default for every person**: their `doctrine-distilled.md` if present,
  otherwise fall back to `doctrine-light.md`.
- **For 5 selected personas**: load *both* variants so we can directly measure
  the lift the richer doctrine provides. Same person → both versions on the
  leaderboard, side-by-side.

The 5 comparison personas (chosen for archetype diversity):

| Persona | Archetype |
|---|---|
| Richard Hamming | scientist / "You and Your Research" |
| Nassim Taleb | probabilistic philosopher |
| Peter Thiel | contrarian VC |
| Paul Graham | founder/essayist |
| Warren Buffett | classic value investor |

The selection is controlled by `LIGHT_VS_DISTILLED_COMPARISON` in
[`evals/papers/scripts/run_eval.py`](../evals/papers/scripts/run_eval.py).
Add a person-slug there to include their light doctrine alongside distilled.

## Vanilla baselines

The runner also adds two model-only baselines (no doctrine) for comparison:

- `vanilla_sonnet_4_6` (Claude Sonnet 4.6)
- `vanilla_opus_4_7` (Claude Opus 4.7)
